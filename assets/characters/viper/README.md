# Viper assets

All Viper art belongs in this folder.

Expected static PNGs:
- `portrait.png`
- `combat.png`

Animation folders:

```
idle/1.png ... x.png
magical/1.png ... x.png
melee/1.png ... x.png
defensive/1.png ... x.png
damage/1.png ... x.png
death/1.png ... x.png
```

Character-specific card effects:

```
effects/magical/1.png ... x.png
effects/melee/1.png ... x.png
effects/defensive/1.png ... x.png
```

Examples:
- `magical/1.png` — Viper playing a magical-class card.
- `melee/1.png` — Viper playing a melee-class card.
- `damage/1.png` — Viper taking HP damage.
- `effects/magical/1.png` — Viper's magical card effect.

Frames always start at `1.png` and continue numerically until the first missing frame.
