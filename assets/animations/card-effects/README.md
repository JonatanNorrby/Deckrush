# Card-class effect PNGs

Each card-play effect has its own folder:

```
magical/1.png
magical/2.png
...
melee/1.png
melee/2.png
...
defensive/1.png
defensive/2.png
...
```

Supported effect folders:
- `magical`
- `melee`
- `defensive`

These effects play in addition to the active character's matching animation. Transparent PNGs are recommended.
