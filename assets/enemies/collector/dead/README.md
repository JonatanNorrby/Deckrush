# Collector dead artwork

This folder contains the persistent defeated pose shown when this enemy has been killed but other enemies in the encounter are still alive.

## Required PNG

`1.png` — static corpse/defeated artwork displayed on the ground.

Expected path:

```
assets/enemies/collector/dead/1.png
```

This is separate from the `death/` animation folder. `death/1.png ... x.png` is the transition animation; `dead/1.png` is the final persistent corpse image.
