# Enemy static PNGs

Static enemy fallback art uses:

`<enemy-id>.png`

Current expected filenames:
- `scrapper.png`
- `bulwark.png`
- `berserker.png`
- `parasite.png`
- `bomber.png`
- `enforcer.png`
- `collector.png`
- `auditor.png`

Animated enemy frames belong under `assets/animations/enemies/<enemy-id>/<state>/1.png ... x.png`.
