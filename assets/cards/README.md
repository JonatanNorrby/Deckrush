# Card PNGs

Each card illustration uses:

`<card-id>.png`

Examples:
- `toxic-cut.png`
- `envenom.png`
- `shield-strike.png`
- `fortify.png`
- `jackpot.png`
- `clean-finish.png`

The filename must exactly match the card's stable `id` in `src/data/cards.js`.

Card art is used in combat, reward choices, and the Handbook. Rectangular art is fine; the UI crops it to the card art window.
