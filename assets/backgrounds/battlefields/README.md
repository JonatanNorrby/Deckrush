# Battlefield backgrounds

Add encounter background images here as numbered PNGs:

```
1.png
2.png
3.png
4.png
5.png
6.png
```

When a fight begins, Deckrush randomly selects one of these six slots using the run RNG and keeps that same background for the entire encounter. Recommended artwork is a wide landscape image suitable for `cover` scaling. Keep important visual detail away from the lower edge where combatants and cards overlap.

If the selected numbered file is missing, `assets/backgrounds/combat.png` remains the fallback.
